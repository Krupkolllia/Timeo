# Timeo

Источник истины по продукту и архитектуре — [TIMEO-SPEC.md](TIMEO-SPEC.md). Все решения там
согласованы с заказчиком и не подлежат переизобретению без явного распоряжения. Читать перед
любой работой над функциональностью.

## Кто пользователь

Конечный пользователь — не разработчик, тестирует изменения удалённо на iPhone 13 Pro через
посредника (заказчика). Отсюда: не ломать production-деплой без крайней необходимости, изменения
проверяются скриншотами, а не догадками.

## Инварианты, которые нельзя нарушать

- Изменения в одном периоде (`periods`) никогда не влияют на суммы в другом периоде — раздел 6.3.
- Ни одно поле ввода не блокирует сохранение (никакой жёсткой валидации) — раздел 8.
- Множители не перемножаются между собой, побеждает одно правило — раздел 6.2.
- Локальная база (Dexie/IndexedDB) — первичный источник данных, экран не ждёт сеть.
- Изменение `period_start_day` запрещено при наличии закрытых периодов.

## Стек

React + TypeScript + Vite, Tailwind v4, Dexie (IndexedDB), Zustand, react-router-dom,
vite-plugin-pwa, Supabase (Postgres + Auth, с блока 7), Cloudflare Pages/Workers.

## Структура

```
src/
  app/        роутинг и корень приложения
  pages/      экраны (раздел 7 ТЗ), один каталог на экран
  components/ переиспользуемые UI-компоненты
  db/         схема Dexie, локальный user_id
  store/      Zustand-хранилища
  lib/calc/   логика расчёта (раздел 6 ТЗ) — чистые функции, без побочных эффектов
  lib/sync/   клиент Supabase, синхронизация
  lib/export/ бэкап/восстановление JSON
  i18n/       словарь текстов (сейчас только ru)
  types/      модель данных (раздел 5 ТЗ)
supabase/sql/ схема и RLS-политики Supabase
workers/      Cloudflare Workers (напоминания, keep-alive)
```

## Правила работы

- Не коммитить и не пушить без явной просьбы.
- Не удалять данные пользователя необратимо — только мягкое удаление (`deleted_at`) с окном отмены.
- `lib/calc/*` — чистые функции, покрываемые модульными тестами; не завязывать на Dexie/React.
- Секреты (Supabase URL/anon key) — только через переменные окружения, не хардкодить.
